# 大气
Complementary 的天空效果并不是像 Eclipse 那样，尝试完整地模拟真实的大气散射过程，而是采用了大量艺术化、风格化的参数控制。因此，在源码中经常可以看到一些看起来非常奇怪的常量和映射函数，它们的目的并不一定是严格对应某个物理过程，而是为了塑造特定的视觉效果。

## 在日出日落时拥有变化更快的参数

看源码：

```glsl
float SdotU = dot(sunVec, upVec);
float sunFactor = SdotU < 0.0 ? 
                  clamp(SdotU + 0.375, 0.0, 0.75) / 0.75 : clamp(SdotU + 0.03125, 0.0, 0.0625) / 0.0625;
```

`SdotU < 0.0`表示太阳在地平线以下。在此基础上，Complementary 对 `SdotU` 做了一次**分段的 0~1 映射**，得到 sunFactor`sunFactor`是一个在地平线附近变化极快的太阳高度权重。

上面代码实际展现的变化曲线是：`SdotU`在`-0.375 ~ 0`，权重变化是 `0.0 -> 0.5`，在 `0 ~ 0.03125`，迅速变化 `0.5 -> 1.0`

> 可以看到，这并不是一个对称的线性映射，而是刻意让地平线附近的参数变化更加敏感，让艺术性的变化更快更明显


> [!tip]
> 手动构造一个 0~1 的 Remap（重映射）函数：
> 
>   `clamp(x + 常量, 0.0, 范围) / 范围`
> 
> 本质上就是把一个数值范围重新映射到 0~1
>

### 分段线性映射
本方法在光影中非常常见。`sunFactor` 就是一个典型例子：**根据不同的输入区间，使用不同的线性函数进行映射**。

例如，现在希望将 [0, 0.4333] 的部分重新映射到 [0, 0.5]，将 [0.4333, 1] 的部分重新映射到 [0.5, 1]，也就是说使前半段变化得稍快，在原本本该是 0.4333 的地方变成了 0.5，于是有下面的映射公式

$$
f(x) = x \times \frac{0.5}{\mu}, x < \mu \\
f(x) = x \times a + b, x \ge \mu \\
\text{其中，a b 满足} \\
\mu a + b = 0.5 \\
a + b = 1.0
$$

依照上面公式即可完成分段线性映射。

### 利用 `smoothstep` 平滑过渡

```glsl
float t = t * t * (3.0 - 2.0 * t);
```

该表达式本质是 GLSL 内置函数 `smoothstep`，`smoothstep` 会将输入映射到 0~1，但相比普通线性映射，它在起点和终点处会平滑地减速，因此非常适合用于光影中的各种过渡效果。

### `mix` 因子平方作用
着色器里经常用到函数：

```glsl
color = mix(a, b ,t)

// 等价于
color = (1 - t) * a + t * b;
```
